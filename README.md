An end-to-end binary classification credit risk scoring pipeline built on **255,000+ loan records**. The pipeline leverages feature engineering, Optuna hyperparameter optimization, and probability calibration to evaluate borrower creditworthiness and power an automated 3-tier underwriting framework.
